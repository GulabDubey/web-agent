# Import Export Code Registration In India
Import Export Code Registration is applicable on every business engaged in import and export of goods or services. Prior to carrying out any export or import activities , it is mandatory to obtain an IEC number from the Directorate General of Foreign Trade (DGFT). Application for issuance of IEC can be made online on DGFT portal.

##  Overview of Import Export Code Registration In India 
Import Export Code (also known as IEC) is issued by the Directorate General of Foreign Trade (DGFT), Ministry of Commerce and Industry. It is a unique 10-digit code and is mandatory for all Companies that deal in import and export. in India. Once IEC is issued, it will remain valid for lifetime.
* * *
## Things to Know
  * **Mandatory for Import/Export**


It is mandatory to obtain IEC for every business involving import/ export.
  * **Online Application**


Application for allotment of IEC can be made online via [dgft](https://www.dgft.gov.in/CP/)
  * **Valid for Multiple Branches**


IEC number allotted to an applicant shall be valid for all its branches/divisions/units.
  * **Exempted Categories**


The following categories of importers or exporters are exempted from obtaining IEC:
  1. Importers covered by clause 3 (1) [except sub-clauses (e) and (l)] and exporters covered by clause 3(2) [except sub-clauses (i) and (k)] of the Foreign Trade (Exemption from application of Rules in certain cases) Order, 1993.
  2. Ministries/Departments of the Central or State Government.
  3. Persons importing or exporting goods for personal use not connected with trade or manufacture or agriculture.
  4. Persons importing/exporting goods from/to Nepal provided the CIF value of a single consignment does not exceed Indian Rs. 25,000.


Persons importing/exporting goods from/to Myanmar through Indo-Myanmar border areas provided the CIF value of a single consignment does not exceed Indian Rs.25,000. 
_However, the exemption from obtaining Importer-Exporter Code (IEC) number shall not be applicable for the export of Special Chemicals, Organisms, Materials, Equipment’s and Technologies (SCOMET) as listed in Appendix- 3, Schedule 2 of the ITC(HS) except in the case of exports by category(ii) above._

## Frequently Asked Questions
##  How can we file online application for obtaining IEC? 
Online application for obtaining IEC can be filed through [https://dgft.gov.in/](https://www.companiesnext.com/\\"https:/dgft.gov.in/\\")  

##  What is the technical requirement for obtaining IEC? 
For obtaining IEC, following information/ documents are required:
  1. Valid PAN
  2. Address Proof
  3. NOC from the owner in case the premises is not in the name of applicant entity
  4. Cancelled cheque bearing entity’s pre-printed name or bank certificate
  5. Mobile No. and E-mail ID


##  How to upload documents online? 
Scanned copy of the document is required to be uploaded online. Only GIF and PDF file formats are allowed with the size not exceeding 5MB. 
##  Do we need a digital signature for submitting application online? 
Digital signature for submitting application for fresh IEC or amendment of IEC is not required effective from 09/08/2018.  

##  Can a person/ entity possess more than one IEC? 
No, only one IEC is issued to a single person/ entity.
